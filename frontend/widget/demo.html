Widget Features

Draggable: Grab the header bar to move the chat window anywhere on screen.

Refresh: Click the refresh icon to start a new conversation.

Auto-reconnect: The widget reconnects automatically if the connection drops.

Markdown: Agent responses render with formatting — bold, lists, tables, code.
